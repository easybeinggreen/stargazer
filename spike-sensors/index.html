Heading: wave a figure-8 to calibrate, then compare to a compass app — outdoors, indoors, next to the laptop.
Update rate: Android throttles the sensor when the phone is still (that's the "settled low"). The number that matters is Hz while you slowly pan the phone across the room — want ~15+ for smooth live AR.
Drift test: aim at a fixed mark, tap Mark heading, set the phone down untouched for 1–2 min, then read Drift since mark. Small (<5°) = stable compass; large = it wanders and we'd correct for it.
